ゲームのエフェクトの使い方（Wan 2.1 Alpha / LayerDiffuse）

← 入口ページ ComfyUI を開く（ポート 8188）→

ComfyUI で、半透明の動く素材（透明度つきの動画）と透明な 1 枚絵を作る。画面では左の Workflows → VFX。 他の PC からは、この入口ページの API で ComfyUI を起動し、ComfyUI の HTTP API（ポート 8188）でワークフローを投げる。

ワークフロー

名前（workflows/ の下）作るもの既定の値
VFX/WanAlpha_T2V.json
VFX/WanAlpha_T2V_api.json		 Wan 2.1 Alpha T2V 14B。透明度つきの動画。RGBA の PNG の連番と、RGBA のアニメ WebP の 2 つを書く 832x480・81 コマ（16 fps で約 5 秒）・LightX2V で 4 ステップ・cfg 1.0・seed 42
VFX/LayerDiffuse_SDXL_RGBA.json
VFX/LayerDiffuse_SDXL_RGBA_api.json		 LayerDiffuse（SDXL base 1.0）。透明な 1 枚絵（RGBA の PNG） 1024x1024・20 ステップ・cfg 7・seed 42。幅と高さは 64 の倍数

出力は ComfyUI の output/dq_vfx_trial/ の下（wan_alpha_png_*.png・wan_alpha_*.webp・layerdiffuse_*.png）。 _api.json は画面の Save (API Format) と同じ形（POST /prompt の prompt）。

GPU は 1 枚を取り合う。ComfyUI を起動すると、Strata・Hunyuan3D・音楽生成などほかの GPU のサービスは止まる。 Wan Alpha は VRAM を 21 GiB ほど使う。

他の PC から API で使う

サーバーの名前は、このページを開いたホスト（<server>）。POST には X-Portal-Request: 1 が要る。

  1. 入口ページの API で ComfyUI を起動し、使えるまで待つ:
    curl -X POST -H "X-Portal-Request: 1" --max-time 660 "http://<server>:8080/api/service/comfyui/start?wait=600"
  2. API 形式のワークフローを読む（/ は %2F に符号化する）:
    curl "http://<server>:8188/api/userdata/workflows%2FVFX%2FWanAlpha_T2V_api.json" -o wan.json
  3. 下の表の入力を書き換え、{"prompt": <wan.json の中身>, "client_id": "任意"} を POST http://<server>:8188/prompt に送る。応答の prompt_id を控える。
  4. GET /history/<prompt_id> を数秒ごとに見る。終わると outputs にファイル名（filename・subfolder・type）が入る。
  5. GET /view?filename=<名前>&subfolder=dq_vfx_trial&type=output で取る。

API の一覧（エンドポイント・入力の対応）は 入口ページの GET /api の comfyui にもある。 Claude Code / Codex からは MCP の localai_comfyui に workflow_name: "VFX/WanAlpha_T2V_api.json" と set: {"6.text": "…", "3.seed": 1} を渡すと、投入から出力の保存まで行う（tools/localai-mcp）。 もっと簡単には localai_vfx に kind（wan_alpha か layerdiffuse）・prompt・seed・ width・height・frames を名前で渡す。

MCP を他の PC に入れる・更新する（終わったら Claude Code を開き直す）。Windows の PowerShell に 3 行を貼る:
$ProgressPreference = 'SilentlyContinue'
Invoke-WebRequest -UseBasicParsing http://<server>:8080/remote/setup-remote.ps1 -OutFile $env:TEMP\setup-remote.ps1
powershell -ExecutionPolicy Bypass -File $env:TEMP\setup-remote.ps1 -ServerIp <server>
cmd から・Linux / macOS からのコマンドは GET /api の mcp（Linux / macOS: curl -fsSL http://<server>:8080/remote/setup-remote.sh | bash -s -- <server>）。
